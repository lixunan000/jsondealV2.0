# JsonDeal · 开发者效率工具箱

一个常用小工具集合：JSON 格式化、JSON 对比、断言代码生成、UID 提取、批量 ID 替换、Groovy SQL 提取、转单规则 SQL 生成、MD5 生成、通用文本对比。

- 无构建、无依赖、无后端 —— 双击 `index.html` 即可运行
- 所有处理在浏览器本地完成，数据不会离开你的机器
- 支持浅色 / 深色主题、响应式布局、命令面板与快捷键
- 另有 **Windows 桌面版**（Electron 打包，含安装包与绿色版），见 `D:\exercise\Coding\jsondeal-mainV2.0-App`

---

## 快速开始

直接双击 `index.html`（或右键 →「用浏览器打开」）。

> 建议使用 Chrome / Edge 等现代浏览器。页面使用 `file://` 协议打开也可以正常工作（未使用 ES Module，因此不受跨域限制）。

目录结构：

```
jsondeal-main2/
├─ index.html          # 单页应用外壳：侧边栏、顶栏、9 个视图
├─ assets/
│  ├─ app.js           # 全部逻辑（IIFE，无全局污染）
│  ├─ styles.css       # 设计令牌 + 组件样式 + 响应式
│  ├─ favicon.svg      # 站点图标
│  └─ bill-rule-template.xlsx   # 转单规则配置模板（页面可下载）
└─ README.md
```

### JSON 格式化
粘贴 JSON 后点击「格式化」即可。输出区带 JSON 语法着色（键名 / 字符串 / 数字 / 布尔 / null 各自配色），可直接复制或下载。JSON 不合法时会在提示条中给出错误信息。

**兼容整体转义的文本** —— 从接口日志里复制出来的 JSON 常带转义引号，直接粘贴也能格式化：

```
{\"inspectResult\":\"1\",\"pk_org\":\"2512556443864399874\"}
```

解析时依次尝试：直接解析 → 当作 JSON 字符串解析后再解一层 → 先反转义再解析；因此 `\"` `\\` `\n` `\uXXXX` 都能正确还原，输出提示会说明「已自动还原转义字符」。同样的宽松解析也应用于 JSON 对比与断言生成。

**排序** —— 点击「排序」按钮，输出区的 JSON 会按 key 的字母顺序重新排列（递归处理所有层级对象，数组的先后顺序保持不变）。比较时先忽略大小写、大小写相同再按编码值比较，结果稳定可复现；「格式化」按钮仍保持原始 key 顺序。

**全屏查看** —— 输出区标题栏左侧的 `⛶` 按钮会把输出面板切换成**沉浸模式**：面板铺满整个窗口、隐藏侧边栏与顶栏，长 JSON 可以一口气看完。点击 `✕` 或按 `Esc` 退出，退出后面板自动回到原来的位置。切换工具时若正处于全屏状态，也会自动还原。

**折叠树视图** —— 输出区不是一屏白花花的 JSON，而是一棵可以收起的树：

- 行号栏左侧的 **折叠箭头**（`▼` / `▶`）点一下即可收起 / 展开该节点的所有子节点，箭头悬停会高亮
- 折叠后该行末尾标出被收起的规模 —— 数组显示 `… 3 项`，对象显示 `… 3 个字段`；点击这段提示也能直接展开
- 「**折叠全部**」把第二层及以下的节点一次性收起（保留根节点展开），「**展开全部**」还原
- 行号始终是**原始行号**，折叠掉的行不会导致后面的编号错位
- 「**复制**」「**下载**」拿到的始终是**完整的格式化 JSON**，与当前折叠状态无关

### JSON 对比
左右各粘贴一份 JSON，点击「对比」：

- **自动排版**：若输入不是 4 空格缩进的规范格式，会先自动格式化再对比（已是规范格式则原样保留）；两边都解析成功才会改写文本，解析失败时保持原样并报错
- 差异按类型分组统计（新增字段 / 删除字段 / 值修改），两侧面板头部实时显示计数
- **逐行精确高亮**：解析原始文本时记录每个路径（`data.items[0].code`）所在的行号，差异直接标注到对应行上
  - 新增 → 高亮 JSON 2 中该键所在行（绿色 + 左侧色条）
  - 缺失 → 高亮 JSON 1 中该键所在行（红色 + 左侧色条）
  - 修改 → 高亮**双方**该值所在行（浅黄色 + 左侧色条，比红绿更柔和）
  - 行号栏同步着色，一眼看出第几行有差异
- 下方「对比结果详情」按类型分组列出每一处差异，并可一键载入示例对比

### JSON 断言生成
输入接口响应 JSON，自动生成断言代码：

```js
assert("张三", resBody.name, "断言name");
assert(25, resBody.age, "断言age");
```

- 只断言**字段值**，不会生成 `length` 断言
- 数组按 `resBody[0].field` 形式逐项展开
- 内置跳过 `pubts`、`tenant` 以及以 `id` 结尾的字段
- 支持「只保留某些字段」与「排除某些字段」两种过滤模式（逗号分隔）

### UID 提取
从日志或文件中提取 UID：

```
InspectOrderRes.java@line[1739]@resId[UID:P_QMSQIT-BE_2487BBFA04880035]=@exit[资源ID不存在]
```

提取结果为 `UID:P_QMSQIT-BE_2487BBFA04880035` —— 遇到空白、引号、逗号、括号、`=`、`@`、`|`、`;` 等分隔符即结束，不会把尾随日志内容带进来。结果自动去重并排序。

结果区**一行一个 UID** 展示，方便逐条核对；点「复制」或「下载」得到的仍是**逗号分隔**的原始格式。

### 批量 ID 替换
输入起始雪花 ID 与 SQL 文本，工具会把 SQL 中的数字 ID 按出现顺序替换为 `起始值 + 1`、`+ 2`…… 结果可复制或下载为 `.sql` 文件。

「起始雪花 ID」输入框后有 **「点击获取」** 按钮，点一下就按 62 位雪花算法实时生成一个 ID 并填入，无需再去别处复制。

### Groovy 提取 SQL
从 Groovy 源码中提取 `UPDATE` / `DELETE` 语句，支持三引号、多行与单行写法。

### 转单规则 SQL
上传转单规则配置 Excel（`.xlsx`），工具会读取表头与数据行，为**每一行**生成一条可直接执行的 `INSERT` 语句：

```sql
INSERT INTO iuap_apcom_businesssflow.domain_make_bill_rule_detail
(id, makebill_id, ..., target_fileld_resid)
VALUES('2664164640452771946', '2664164073513418780', 'define20', ..., NULL);
```

生成规则：

| 项 | 规则 |
| --- | --- |
| `id` | 界面上填写「起始雪花 ID」，逐行自增（起始值、起始值 + 1、第 N 行 = 起始值 + N - 1），用 `BigInt` 计算不丢精度；输入框后的 **「点击获取」** 按钮可按雪花算法直接生成一个填入 |
| `makebill_id` | 界面上填写一次，所有行共用；输入框后的 **「点击获取」** 按钮可按雪花算法直接生成一个填入 |
| 首行带红色 `*` 的列 | **必填**，为空时生成前逐行提示「第 N 行：xxx 为必填项，不能为空」，不会产出半成品 SQL |
| 其他非必填列 | 为空时写入 `NULL` |
| `is_business_object`（J 列） | 默认 `0`，用户填写则用用户的值；**填 `6` 时**，`target_field_type` 与 `origin_field_type` 自动写入字符串 `Characteristics` |
| `micro_service_code`（K 列） | 默认 `yonbip-mm-qms`，用户填写则用用户的值 |
| `pubts` | 生成时刻的 `yyyy-MM-dd HH:mm:ss` |
| 「target 字段中文」列 | 仅供人阅读，**不写入** SQL |

- Excel 在浏览器内解析（不依赖任何第三方库），支持拖拽或点击选择文件
- 页面右上角「下载模板」可获取官方模板 `转单规则配置模板.xlsx`（位于 `assets/bill-rule-template.xlsx`），下载后直接填写再上传即可
- 生成的 SQL 可复制或下载为 `.sql` 文件，逐条独立执行

### MD5 生成
粘贴文本内容，点击「计算 MD5」得到 32 位小写十六进制摘要，可直接复制或下载为 `md5.txt`。

计算前会先把换行统一成 **LF**（`\r\n` 与单独的 `\r` 都规范成 `\n`），与 Git 在 `core.autocrlf` 下入库的内容保持一致 —— 因此同一份文本无论在 Windows 还是 Linux 上粘贴，结果都相同。

- MD5 为自研实现（RFC 1321），不依赖任何第三方库，也不使用 `crypto.subtle`（后者仅支持 SHA 系列）
- 文本按 **UTF-8** 编码后参与计算，中文等内容不会乱码
- 结果区只输出**一个**摘要值

### 文本对比
左右各放一份文本（SQL / Java / 日志 / 配置均可），点击「对比」：

- **逐行对齐**：先掐掉公共头尾，再对中段做最短编辑脚本搜索，得到「相同 / 删除 / 新增」的操作序列
- **差异直接标在原文上**：删除行标红、新增行标绿、成对出现的「删除 + 新增」视为**修改**并标黄，行号栏同步着色
- **行内字符级高亮**：配对的两行再做一次词级切分，把真正改动的字符标出来（`LIMIT 100;` → `LIMIT 200;` 只标 `1` 与 `2`）
- **比较选项**：「忽略空白差异」「忽略大小写」只影响**匹配用的键**，原文始终按你输入的样子展示，不会被改写
- **上下文行数**：`0`（只看差异行）/ `3`（标准 unified diff）/ `全部`（完整内容）
- **标准 unified diff**：「复制 Diff」「下载 .diff」得到的是带 `@@ -a,b +c,d @@` 头的补丁文本，可直接 `patch` / `git apply`
- 「打开文件」载入本地文本；**UTF-8 优先，识别失败自动按 GBK 兜底**（中文日志常见）
- 「交换两侧」可反向对比，「清空」重置全部内容

## 界面说明

- **侧边栏**：工具导航 + `⇧1`~`⇧9` 快捷键角标；窄屏下自动收起为顶栏菜单按钮
- **顶栏**：当前工具标题与说明、换行开关、命令面板入口、主题切换
- **工作区**：左侧输入、右侧输出，两侧独立滚动；输入区带行号栏，JSON 格式化的输出区行号栏另带折叠箭头（可收起 / 展开子树）
- **沉浸模式**：输出面板可一键全屏（`⛶`），铺满窗口便于长时间阅读，`Esc` 退出
- **结果区始终自动换行**：长 SQL / 长 JSON 不用横向滚动即可读完；行号会按折行后的实际行数自动对齐
- **局部全选**：点击右侧结果框后按 `Ctrl` + `A`，只选中该结果框里的文本，不会连整个页面一起选；输入框内同理保持浏览器原生行为
- **顶栏「自动换行」**：控制输入区的折行（结果区始终换行）
- **主题**：右上角一键切换，选择结果记在 `localStorage`，下次打开自动恢复
- **提示条**：右下角浮出，成功 / 失败 / 警告各有配色

## 技术说明

- 纯 HTML + CSS + JavaScript，classic `<script>` 引入，**不使用 ES Module / 打包器**，保证 `file://` 直开可用
- 路由基于 `location.hash`（`#/format` 等），刷新后停留在当前工具
- 样式基于 CSS 自定义属性（设计令牌），深色主题通过 `<html data-theme="dark">` 覆盖令牌实现
- JSON 语法高亮由一个轻量分词器完成（`tok-key` / `tok-str` / `tok-num` / `tok-bool` / `tok-null`）
- JSON 折叠树基于 `JSON.stringify` 的固定排版规律（4 空格缩进、每行一个键 / 元素）还原层级：栈式配对开启行与收尾行，得到每个节点的父子关系与直接子节点数；渲染时按父子链判断某行是否被折叠的祖先隐藏，因此折叠 / 展开只是重排「可见行」，`canonical` 始终保留完整文本
- 行号栏绝对定位，不参与容器高度计算 —— 左侧内容再多也不会把右侧面板和下方按钮撑出屏幕
- 对比高亮采用「透明 textarea 覆盖层 + 同步滚动」方案，保留原生编辑体验；覆盖层按行渲染，配合自研的「路径 → 行号」索引实现精确定位
- 雪花 ID 使用 `BigInt` 计算，避免大整数精度丢失
- 「点击获取」生成的雪花 ID **完全对齐主流微服务平台的 62 位雪花 ID 生成器**：
  `((unix秒 - 1483200000) << 33) | (dataCenterId << 25) | (workerId << 19) | (领域位 << 18) | 序列(18位)`，
  纪元 `1483200000` = 2017-01-02 00:00:00（北京时间）；节点号在一次会话内固定，序列号随机取且保证严格递增不重复
- 面板全屏（沉浸模式）时会把面板临时挂到 `body` 下的独立层，退出时原位放回 —— 视图的入场动画会残留 `transform`，若不脱离该祖先，`position: fixed` 会被限制在视图内而铺不满窗口
- Excel 解析为自研实现：读取 ZIP 中央目录 → `DecompressionStream('deflate-raw')` 解压 → `DOMParser` 解析 `workbook.xml` / `sharedStrings.xml` / `sheet1.xml`，不引入任何第三方库
- MD5 为自研实现（RFC 1321）：文本先经 `TextEncoder` 按 UTF-8 编码，再走自实现的分块压缩函数；换行在编码前统一为 LF
- 文本对比采用 Myers O(ND) 差分（自研）：每层只记录 `k ∈ [-d, d]` 的推进量，内存 O(D²) 而非 O(D × 行数)；差异过大时按位置配对兜底，保证超大文件也不会把页面拖死
